# September 2026

*Platform release `2026.09`. Mobile app 1.2.*

**In one line:** account security became a first-class, visible feature on every client, and the
catalogue learned to tell a broken source from a dead camera.

---

## Highlights

**One security centre, three products.**
The website, the mobile app and the VolveMenu management app now all show the same thing: every
session signed in to your account, where and when it was last used, a record of recent security
events, and a button to end any session from any device. Ending a session takes effect everywhere,
immediately.

**A flapping camera source no longer looks like hundreds of dead cameras.**
A single upstream provider having a bad hour used to be indistinguishable from its cameras being
gone, which meant good cameras were switched off in bulk. They are now told apart, and cameras
switched off by that fault have been recovered.

**Search visibility repairs.**
Several long-standing issues were fixed: accented characters in camera and place names were being
stripped rather than normalised, and a camera missing in one language behaved differently from a
camera missing in another. Both quietly cost us visibility in non-English markets.

---

## By product

### Web platform
- `Added` Account security centre: active sessions, recent security events, remote sign-out.
- `Changed` A camera that does not exist now responds identically in all four languages.
- `Fixed` Accented characters in camera and place names are normalised instead of deleted.
- `Fixed` Advertising click-throughs follow the viewer's language.
- `Added` Verification for two more regional search engines, extending reach beyond the big three.

### Mobile apps (1.2)
- `Added` The security centre, matching the website.
- `Changed` Sign in with Apple now follows Apple's presentation rules exactly.
- `Changed` Revoked sessions sign the app out cleanly rather than failing silently.
- `Fixed` The map no longer moves a camera to a point hidden behind the bottom sheet.
- `Changed` The mascot appears only where a screen would otherwise be empty.

### VolveMenu
- `Added` The security centre in the management app.
- `Changed` A wall-mounted screen is never signed out by accident.
- `Fixed` A support link that broke in languages the website does not serve.
- `Changed` Android build requests only the permissions it needs.

### Platform, behind the scenes
- `Reliability` Camera health checks now rotate through the catalogue nightly instead of hammering
  everything at once, and an unhealthy source is isolated rather than trusted.
- `Performance` Repeated browser permission checks are cached, cutting a network round trip from many calls.
- `Security` Account and session handling was hardened following an independent review. Reported in
  aggregate by policy: see [what we publish](../../docs/what-we-publish.md).

### Brand
- `Added` The mascot rebuilt as a 3D asset, usable across products instead of redrawn per surface.
