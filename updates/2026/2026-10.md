# October 2026

*Platform release `2026.10`, in progress, last updated 2026-10-08. VolveMenu 1.1 for iOS is submitted to
App Store review and not yet released; the Android update is built and not yet in Google Play.*

**In one line:** VolveMenu grew from a phone app into a full venue toolkit, with a web workspace, guest
ordering and the owner's controls a real venue needs.

---

## Highlights

**VolveMenu now has a web workspace.**
Owners can run their screens from a computer as well as a phone. Signing in takes a scan of a code
with the phone that is already signed in, so there is no new password to remember. The workspace
holds the venue's dishes in one catalogue, menu editing with a live preview of the screen, screens,
schedules, promotions, orders, reviews, the team and a report of what the screens actually showed.
It is live at [menu.volvevision.com](https://menu.volvevision.com), with a help centre alongside it.

**Guests can order from the table.**
A tablet on the table or a code printed for each table opens the same menu on the guest's own
phone, in their language, and an order goes straight to the staff board with the table number on it.
Guests can also leave a rating and a comment, which the owner reads in one place.

**The controls a venue with a team needs.**
Menus switch by themselves on a schedule, by time of day and optionally by weather. Promotions such
as a happy hour start and stop on the clock. Several venues can run as one chain with shared menus and
their own prices and stop lists. Managers can be given access, and changes they make can wait for the
owner's approval before reaching the screens.

## By product

### VolveMenu
- `Added` Web workspace, signed in by scanning a code with the phone app. Live.
- `Added` One catalogue of dishes per venue, used by every menu, with sizes, nutrition, allergens,
  photos and video, in six languages.
- `Added` Import and export of dishes from spreadsheets and from point-of-sale exports, with a check
  before anything changes and a one-step undo.
- `Added` Guest ordering from table tablets and per-table codes, with the table number on every order.
- `Added` Guest ratings and comments, collected in one place for the owner.
- `Added` Scheduled menus by time of day and weather, timed promotions, and an urgent message across
  every screen.
- `Added` Chains: several venues sharing menus, each with its own prices, stop list and screens.
- `Added` Team roles and owner approval of changes made by managers.
- `Added` A report of what every screen actually displayed, and when.
- `Added` A help centre for owners.
- `Added` An overview page that opens first: setup steps that tick themselves for a new venue, then today at a
  glance with screens, orders, ratings, the stop list and anything that needs attention.
- `Added` A search box that opens from anywhere with a keyboard shortcut and finds sections, dishes, menus, screens
  and common tasks.
- `Changed` Every empty section now explains what belongs there and offers the next step, and each section shows a
  short hint on the first visit.
- `Added` The management app gained the same tools as the web workspace, including spreadsheet
  import and a live picture of what any screen is showing. This is in version 1.1, submitted to App
  Store review and not yet released; the Android build is not yet in Google Play.

### Web platform
- `Performance` Pages no longer jump while advertising loads, and more pages can be served from the
  edge instead of being built on every visit.
- `Changed` A camera that is temporarily offline keeps the information search engines use to
  describe it, so a short outage does not cost the page its standing.
- `Fixed` Several popular cameras that had gone dark were brought back with working streams.

### Platform, behind the scenes
- `Reliability` Daily automated monitoring of search health, which flags sudden traffic drops and
  unexpected pages before they cost visibility.
- `Reliability` Large sitemaps are split into smaller parts and list only the languages a page is
  actually published in.
